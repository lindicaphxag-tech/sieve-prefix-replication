# TRACE EVIDENCE V2：口径修正 + 三张新表（2026-11-24）

本文件取代 `TRACE_EVIDENCE_UPDATE.md` 里那两行数字。改动原因：之前把 σ_cross 写成了“占全部块访问的比例”，而定义是“占全部**复用**访问的比例”，两者差一个首次触达项，chutes 上差 0.15，必须改。

## 1. 口径修正

| trace | 复用访问（块） | 其中跨 session | σ_cross = 跨/复用 | 旧数字（含首次触达的错口径） |
|---|---|---|---|---|
| freeinference | 616,661,812（104,751,007 + 511,910,805） | 104,751,007 | **0.1699** | 0.1596 |
| chutes | 464,123,450（299,385,184 + 164,738,266） | 299,385,184 | **0.6451** | 0.4960 |

旧数字恰好等于 σ×(1−首次触达占比)，可反推：freeinference 0.1596=0.1699×0.939；chutes 0.4960=0.6451×0.769。已在 ReScience #161 下追加更正。

## 2. F(τ)：跨 session 复用中“池能活到复用发生”的份额

τ = C/λ，λ 为新增块速率（freeinference 65.4 块/s（39.58 M/604,795 s），chutes 12.34 块/s（139.52 M/11,305,701 s））。

| 池 | freeinference τ | F(τ) | chutes τ | F(τ) |
|---|---|---|---|---|
| 16k | 251 s | 0.978 | 1,328 s | 0.890 |
| 64k | 1,002 s | 0.978 | 5,311 s | 0.942 |
| 256k | 4,008 s | 0.988 | 21,243 s | 0.967 |
| 1M | 16,033 s | 0.994 | 84,974 s | 0.989 |

跨 session 间隔均值：freeinference 404 s（最大 577,140 s）、chutes 7,218 s（最大 9,519,854 s）。两条 trace 的 F 都很高，因为间隔分布被亚秒级重复主导。

## 3. 跨 session 复用的重访集中度（ impacto：SIEVE 能否靠计数区分热冷）

| trace | 有跨 session 复用的块 | 跨复用落在 1 / 2 / 3–4 / 5–8 / 9–32 / >32 次重访块上的份额 |
|---|---|---|
| freeinference | 7,112,880 | 0.0196 / 0.0195 / 0.0292 / 0.0538 / 0.2546 / **0.6232** |
| chutes | 45,652,998 | 0.0645 / 0.0572 / 0.0844 / 0.0972 / 0.2192 / **0.4775** |

两条 trace 的重访都高度集中在 >32 次的块上（62%、48%），所以“计数能否区分热冷”在两个 trace 上都成立——这直接推翻了我们原来打算写进框架的“多重性因子”。

## 4. 于是定律只能写成必要条件的合取，而不是充分条件

六个 regime 的全量读数（Δ 为 SIEVE−LRU）：

| regime | σ_cross | F(τ) @ 工作点 | 命中率 | π | Δ |
|---|---|---|---|---|---|
| conversation 1733 blocks | 0.995 | ~1 | 0.098 | 0 | **+24.6%** |
| toolagent 1733 | 0.41 | ~1 | 0.453 | 低 | +1.9% |
| synthetic 1733 | 高（同链但只深 1 块） | ~1 | 0.050 | 0 | −4.5% |
| agentic | ~1 | ~1 | 0.634 | **~0.65** | −0.6% |
| freeinference 64k | 0.170 | 0.978 | **0.918** | 0 | +0.014 pp |
| chutes 64k | 0.645 | 0.942 | 0.727 | 0 | **−1.70 pp** |
| chutes 256k | 0.645 | 0.967 | 0.749 | 0 | −0.16 pp |

能确定的边界（不是猜测）：

- 命中率 ≥0.9 或 π 高时，增益归零（freeinference、agentic）；
- σ_cross 低时（freeinference 0.17），即使 F 高、命中率不高，也没有可赚的东西；
- σ 高、F 高、命中率中等时（conversation 0.995/~1/0.098、toolagent 0.41/~1/0.453）为正。

**未能解释的观测**：chutes @64k 同时满足上面三条（0.645/0.942/0.727），却输 1.70 pp；4× 池后输幅只剩 0.16 pp。我们暂不编故事。两个候选解释都要下一轮实验才能分辨：

1. chutes 的单请求链极长（603.6 M 块 / 515,817 请求 ≈ 1,170 块/请求），而命中发生在前缀头部；SIEVE 的“优先淘汰最新”在前缀深处占主导的负载上系统性不利，与跨流复用无关。
2. 回放把 π 强制为 0，而 chutes 真实部署的并发可能很高，π 一上来，两条 trace 的可比性就断了。
